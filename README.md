# 🎯 MAO游戏系统

## 📋 项目简介

MAO游戏是一个基于区块链的转盘游戏系统，支持MAO和PI两种代币，具有完整的用户验证机制和安全防护措施。

## 🌟 主要特性

### 🎮 游戏功能
- **转盘游戏**: 经典的转盘抽奖游戏
- **双代币支持**: 支持MAO和PI两种代币
- **多级奖励**: 6个奖励等级，最高100倍奖励
- **用户等级**: 青铜到钻石的等级系统
- **社交功能**: 邀请码、排行榜、分享功能

### 🔐 安全特性
- **智能合约安全**: 使用OpenZeppelin安全库
- **用户验证**: 多重验证机制防止机器人
- **行为监控**: 实时用户行为分析
- **设备指纹**: 唯一设备识别
- **时间验证**: 操作时间间隔验证

### 🛡️ 技术架构
- **前端**: HTML5 + CSS3 + JavaScript
- **区块链**: 以太坊智能合约
- **钱包集成**: MetaMask支持
- **验证系统**: 实时监控和异常检测

## 🚀 快速开始

### 访问游戏
- **生产环境**: https://maopi.me
- **测试环境**: https://maopi.me/user-verification-test.html

### 游戏规则
1. 连接MetaMask钱包
2. 选择代币类型（MAO或PI）
3. 点击开始游戏
4. 等待转盘停止
5. 查看游戏结果
