⚙️ 第4步：编译合约

  1. 点击左侧 Solidity编译器 图标（齿轮⚙️）
  2. 确保编译器版本是 0.8.19 或更高
  3. 点击 Compile UltraSecureWheelGame.sol 按钮
  4. 等待看到绿色的 ✅ 编译成功

🚀 第5步：部署合约

  1. 点击左侧 Deploy & Run 图标（以太坊标志）
  2. 在 ENVIRONMENT 选择 Injected Provider - MetaMask
  3. 这会触发TP钱包连接请求，在手机上确认连接
  4. 确保网络显示为 AlveyChain (3797)

💰 第7步：执行部署

  1. 点击橙色的 Deploy 按钮
  2. TP钱包会弹出确认界面
  3. 检查Gas费用（约0.1-0.2 ALV）
  4. 在TP钱包中点击确认
  5. 等待3-10分钟完成部署
